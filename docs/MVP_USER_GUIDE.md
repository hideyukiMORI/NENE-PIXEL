# NENE-PIXEL MVP 利用案内 / release notes

対象: Android 8.0（API 26）以降、プロジェクト形式 v1。M3 / Issue #89。
アプリの「ファイル → このバージョンについて」でも、英語・日本語・簡体字中国語で制限を確認できます。

## 描く・表示を変える

「ファイル → 新規ドキュメント」で幅・高さをそれぞれ 1～256 ピクセルに指定します。
固定の8色パレットから色を選び、鉛筆または消しゴムで描きます。消しゴムは透明にします。
1回の描画ジェスチャーを1操作として戻す・やり直すことができます。
履歴は最大64操作、変更量が大きい場合は保持できる操作数が少なくなります。
2本指で拡大・縮小・移動します。表示の移動は絵のピクセルや履歴を変更しません。

設定から、机上／手持ちの配置、操作側の左右、深い紫を基調にしたダーク／Ubuntu風ライトを切り替えられます。
外観・配置は現在の編集セッションの設定です。言語はシステムに従う／英語／日本語／簡体字中国語から選択でき、
アプリを閉じても保持されます。文字表示には Android のシステムフォントを使用します。

## 保存・開く・PNG

「名前を付けて保存」は Android のファイル選択画面で**毎回新しいファイル**を作成します。
既存ファイルへの上書き保存はありません。編集を続けるために `.nenepixel` を保管してください。
保存の完了表示を確認してからアプリを閉じます。保存直後は現在の履歴を維持します。
再読み込みすると同じドキュメント ID・リビジョン・全画素を復元し、保存済み状態で履歴は空になります。
ツール・ズーム・外観・パレット設定はプロジェクトファイルに含みません。

「PNGを書き出し」は実寸の全画素と透明度を保持した画像を新規作成します。
ズームや背景のチェック模様は画像に入りません。PNG出力はプロジェクトの保存済み状態を変更しません。
現バージョンには PNG 読み込み機能がないため、PNGだけで編集用プロジェクトを代替できません。

保存・読み込みの失敗やキャンセルでは、編集中の確定済み内容を保持します。
失敗した新規保存先に不完全なファイルが残ることがあります。そのファイルを完成品として扱わないでください。
保存先のクラウド同期やストレージ事業者による、その後の障害までは保証しません。

## 未保存の作業を復旧する

アプリ内には、最後に書き込み・検証が完了した未保存内容を保持する自動保存領域があります。
次回起動時の復旧案内で、復旧するか破棄するかを選びます。選ぶ前に絵を自動で置き換えることはありません。
復旧した絵は**未保存・履歴なし**なので、確認して名前を付けて保存してください。

自動保存は全操作の即時耐久化を保証しません。通常の待機目標は無操作後1秒、操作が続く場合は5秒ですが、
I/O、実行中のファイル操作、未選択の復旧案内などで遅延します。中断直前の操作が含まれないことがあります。
アプリのアンインストールやデータ消去で復旧内容は失われます。復旧領域をプロジェクトの保管先にはしないでください。

## 現在の範囲と互換性

オフラインの単一フレーム・単一レイヤー編集が対象です。パレット編集／JSON交換／減色読み込み、スポイト、
長押しのクイック選択、複数レイヤー、トレース画像、アニメーション、タイル・マップ制作は今後の拡張です。
M4以降の設計・順序は GitHub Issues を正本とし、この案内を実装済み機能の一覧として使います。

プロジェクト形式 v1 のみを読み書きします。未知の新バージョン、破損、制限超過のファイルは開かず、現在の作業を保持します。
将来の形式変更では、v1の作品を保持する明示的な移行方針とテストが先に必要です。
現在のv1にレイヤー・アニメーション用の独自フィールドを追加して保存しないでください。
詳細は [形式の正本](PROJECT_FORMAT_V1.md) と [ADR 0014](adr/0014-project-format-storage-recovery.md) を参照してください。

これは開発中のMVPの案内であり、Play Storeでの製品公開を意味しません。
検証条件と結果は [M3統合受入](quality/M3_DURABLE_MVP_ACCEPTANCE.md) に記録します。
